# ADG099 — suppression-without-reason

**Default severity:** warn

## What it detects
An added `# adg: allow <IDs>` comment that has no `reason="..."`, or an empty one.

The inline suppression syntax is:

```python
total = 0  # adg: allow ADG010 reason="placeholder until the pricing service ships"
```

- One or more rule IDs, comma-separated: `# adg: allow ADG003, ADG004 reason="..."`.
- The reason is a single- or double-quoted string and must not be blank.
- The comment must sit on the line the finding points at.

A suppression **without a reason does not suppress anything**: the original finding is
still reported, plus this ADG099 finding.

## Why it matters
Suppressions are how a reviewer accepts a flagged change on purpose. Without a reason, a
suppression is just another way to make the tool go quiet, which is the behaviour adg
exists to catch. Every valid suppression is listed in the report so it stays visible.

## Example — flagged
```python
def legacy_hook(event):  # adg: allow ADG010
    pass
```

## Example — not flagged
```python
def legacy_hook(event):  # adg: allow ADG010 reason="hook kept for plugin API v1"
    pass
```

## Scope and known false positives
- Only comments on added lines are checked.
- A finding that is not tied to a line (ADG001 for a removed test) is suppressed by an
  allow for its rule **anywhere in that file**, and is listed with its reason like any
  other suppression. A deleted file has no head source to hold a comment; use `exclude`
  or `disable` in `[tool.agent-diff-guard]` instead.
- Files that fail to tokenize are not analysed.
