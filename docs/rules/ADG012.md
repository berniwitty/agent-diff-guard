# ADG012 — exception-swallowed

**Default severity:** warn

## What it detects
A new catch-all exception handler whose body throws the error away:

- the handler is `except:`, `except Exception:`, `except BaseException:`, or a tuple that
  includes one of them (with or without `as name`);
- its body is only `pass`, `...`, or `return <constant>` (including `return` and
  `return None`).

Handlers are compared between base and head by their exception type and body, so an
existing handler that moved is not reported. Any Python file is checked.

## Why it matters
Wrapping failing code in `try/except: pass` makes errors and failing tests disappear
without fixing anything, and hides the next real failure too.

## Example — flagged
```python
def load_settings(path):
    try:
        return parse(path.read_text())
    except Exception:
        return {}
```

## Example — not flagged
```python
def load_settings(path):
    try:
        return parse(path.read_text())
    except FileNotFoundError:
        return {}
```

## Scope and known false positives
- Deliberate best-effort code (cleanup in `__del__`, optional telemetry) is reported.
  Record why with `# adg: allow ADG012 reason="..."` on the `except` line.
- Handlers that log and then swallow are not reported.
- Files that fail to parse are not analysed.
