# ADG002 — test-skipped

**Default severity:** error

## What it detects
A test that ran at base no longer runs at head because the change added:

- a skip/xfail decorator on an existing test function or test class:
  `pytest.mark.skip`, `pytest.mark.skipif`, `pytest.mark.xfail`, `unittest.skip`,
  `unittest.skipIf`, `unittest.skipUnless`, `unittest.expectedFailure`;
- a skip call inside an existing test: `pytest.skip()`, `pytest.xfail()`,
  `self.skipTest()`, `raise unittest.SkipTest(...)`;
- a module-level skip in an existing test file: `pytestmark = pytest.mark.skip(...)` or a
  module-level `pytest.skip(..., allow_module_level=True)`;
- a `return` as the first statement of an existing test function.

Names are resolved through the file's imports, so `from pytest import mark` followed by
`@mark.skip` is detected. Only test files (see `classify.py`) are checked.

## Why it matters
Skipping a failing test is the fastest way to make CI green without fixing anything.
The suite reports success while the behaviour the test protected is no longer checked.

## Example — flagged
```python
# before
def test_parse_negative():
    assert parse("-3") == -3

# after
@pytest.mark.skip(reason="flaky")
def test_parse_negative():
    assert parse("-3") == -3
```

## Example — not flagged
```python
# before
@pytest.mark.skipif(sys.version_info < (3, 11), reason="needs 3.11")
def test_tomllib():
    ...

# after: the existing marker's condition changed, no new skip was added
@pytest.mark.skipif(sys.version_info < (3, 12), reason="needs 3.12")
def test_tomllib():
    ...
```

## Scope and known false positives
- Tests that are **new** in this diff are not checked: a newly added skipped test did not
  remove any coverage that existed at base. Removing a test and re-adding it under a new
  name is ADG001's job.
- A legitimate platform or version `skipif` added to an existing test is flagged. Use
  `# adg: allow ADG002 reason="..."` to record why.
- `pytest.importorskip` is not treated as a skip.
- Files that fail to parse at base or head are not analysed.
