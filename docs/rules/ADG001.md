# ADG001 — test-removed

**Default severity:** error

## What it detects
A test that existed at base is gone at head:

- a test file that contained test functions was deleted, or
- a `test*` function (module level, or a method of a class) present at base is missing
  from the same file at head.

Test functions are matched by qualified name (`TestCalc.test_add`). A missing test is
not reported when a test that is **new anywhere in the diff** has a body at least 80%
similar to it (compared on the normalised source of the body, docstring excluded).
That covers renamed tests, tests moved to another file, and renamed or split test files.

Only test files (see `classify.py`) are checked.

## Why it matters
Deleting the failing test is the bluntest way to get a green suite. In a large diff a
removed test is easy to miss because removed lines draw less attention than added ones.

## Example — flagged
```python
# before: tests/test_calc.py
def test_add():
    assert add(2, 3) == 5

def test_divide_by_zero():
    with pytest.raises(ZeroDivisionError):
        divide(1, 0)

# after: test_divide_by_zero is gone and nothing similar was added
def test_add():
    assert add(2, 3) == 5
```

## Example — not flagged
```python
# before
def test_sub():
    assert sub(5, 3) == 2

# after: renamed, same body
def test_subtract():
    assert sub(5, 3) == 2
```

## Accepting a deliberate removal
A removed test has no line left to annotate, so the allow comment can go anywhere in the
test file and covers this rule's findings for that file:

```python
# adg: allow ADG001 reason="placeholder test replaced by test_check_formats once JSON shipped"
```

The report lists each suppressed removal with the reason. For a deleted test file, use
`exclude` or `disable` in `[tool.agent-diff-guard]`.

## Scope and known false positives
- A test whose body was rewritten **and** renamed in the same change is reported.
- Consolidating several tests into one parametrized test is reported for each removed
  test whose body is not similar enough to the new one.
- Deleting a test file with no test functions (helpers, data) is not reported.
- Files that fail to parse at base are not analysed.
