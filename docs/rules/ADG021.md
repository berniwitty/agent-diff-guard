# ADG021 — gate-loosened

**Default severity:** error

## What it detects
Changes to configuration that make a quality gate easier to pass.

**Coverage threshold** (`pyproject.toml` `[tool.coverage.report]`, `setup.cfg` /
`tox.ini` `[coverage:report]`, `.coveragerc` `[report]`): `fail_under` lowered or
removed.

**Ruff** (`pyproject.toml`, under `[tool.ruff]` or `[tool.ruff.lint]`): new codes in
`ignore` / `extend-ignore`, new entries in `per-file-ignores` /
`extend-per-file-ignores`.

**Mypy** (`pyproject.toml` `[tool.mypy]` and its `overrides`; `setup.cfg` / `mypy.ini`
`[mypy]` and `[mypy-<module>]`): `strict` turned off, new `disable_error_code` codes,
new `ignore_errors = true`.

**GitHub Actions workflows** (`.github/workflows/*.yml|yaml`): a workflow runs a
check tool fewer times than before (`pytest`, `ruff`, `mypy`, `flake8`, `pylint`,
`pyright`, `black`, `isort`, `tox`, `nox`, `coverage`, `unittest`, `pre-commit`, `adg`),
including when the workflow is deleted; a new `continue-on-error: true`; a new `|| true`.

## Why it matters
Lowering the bar is a quicker route to green CI than meeting it. These edits are short,
live in files reviewers skim, and change what every later commit is checked against.

## Example — flagged
```toml
# before
[tool.coverage.report]
fail_under = 90

# after
[tool.coverage.report]
fail_under = 70
```

## Example — not flagged
```toml
# Raising a threshold or removing an ignore tightens the gate.
[tool.coverage.report]
fail_under = 95
```

## Scope and known false positives
- Workflow checks look at lines, not parsed YAML: renaming a step's tool, moving a
  command into a script, or a tool name in a step title can shift the counts.
- Adding paths to ruff `exclude` / `extend-exclude` is not reported.
- `flake8`, `pylint` and `pyright` configuration files are not inspected.
- Findings on removed workflow commands have no line. A YAML file cannot hold an inline
  `adg: allow`, so accept them with `disable` or `exclude` in `[tool.agent-diff-guard]`.
- Files that fail to parse (invalid TOML or INI) are not analysed.
