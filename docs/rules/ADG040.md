# ADG040 — uncovered-change

**Default severity:** info

## What it detects
Added lines in non-test Python files that the test suite measured but never executed.
Requires a Cobertura XML coverage report:

```bash
pytest --cov --cov-report=xml        # or: coverage xml
adg check --base origin/main --coverage coverage.xml
```

Without `--coverage` the rule does nothing. Consecutive uncovered added lines are
reported as one finding at the first line.

Paths in the report are mapped to repository paths through its `<source>` entries
(absolute sources under the repository root, or relative ones such as `.` written with
coverage.py's `relative_files = true`).

## Why it matters
New code that no test runs can be anything, including a stub or a special case, and
nothing will notice. It is the cheapest signal that a change's tests do not exercise it.

## Example — flagged
```python
def refund(order):
    if order.is_gift:          # added; never executed by the tests
        return issue_voucher(order)
    return reverse_charge(order)
```

## Example — not flagged
```python
# Lines the coverage report does not measure (blank lines, comments, docstrings) and
# files absent from the report are ignored.
```

## Scope and known false positives
- The report must match the code being checked; a stale `coverage.xml` gives stale
  findings.
- Code only reachable on another platform or Python version is reported.
