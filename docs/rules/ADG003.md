# ADG003 — assertion-weakened

**Default severity:** error

## What it detects
Within a test function present at base and head (same file, same qualified name):

1. **Fewer assertions.** The number of assertions dropped. Counted: `assert`
   statements, `self.assert*()` calls, any `*.assert*()` call (mock assertions),
   `pytest.raises` and `pytest.warns`. Not checked when the test gained a
   `pytest.mark.parametrize` marker, because folding cases into parameters is a
   common legitimate refactor.
2. **Exact → weak.** The test lost exact assertions and gained weak ones. Exact:
   comparisons (`==`, `!=`, `<`, `in`, `is` …), value-comparing predicates
   (`isclose`, `allclose`, `array_equal`), `assertEqual`-style methods,
   `pytest.raises`/`assertRaises` with a specific exception or `match=`. Weak:
   truthiness of a name, attribute or call result (`assert x`, `assert not x`,
   `assert parse(s)`, `assert isinstance(x, T)`), `is not None`,
   `assertTrue`/`assertFalse`/`assertIsNotNone`/`assertIsInstance`,
   `pytest.raises(Exception)` and `assertRaises(Exception)` without `match`.
3. **Always-passing assertion.** A new `assert True`, `assert 1`, `assert "x"`,
   a comparison between two literals, or `assertTrue(<truthy literal>)`.
4. **Widened tolerance.** A `pytest.approx(expected, rel=…, abs=…)` whose `rel` or
   `abs` grew. Calls are paired by their `expected` argument. pytest's defaults
   (`rel=1e-6`, `abs=1e-12`) apply when an argument is omitted.

## Why it matters
A weaker assertion keeps the test name and the green tick while checking much less.
`assert result == 42` → `assert result is not None` passes for every wrong answer.

## Example — flagged
```python
# before
def test_parse():
    assert parse("42") == 42

# after
def test_parse():
    assert parse("42") is not None
```

## Example — not flagged
```python
# before
def test_parse():
    assert parse("1") == 1
    assert parse("2") == 2

# after: same checks, folded into parameters
@pytest.mark.parametrize(("text", "value"), [("1", 1), ("2", 2)])
def test_parse(text, value):
    assert parse(text) == value
```

## Scope and known false positives
- Moving assertions into a helper function lowers the count and is reported.
- `unittest.assertAlmostEqual(places=…/delta=…)` and `math.isclose` tolerances are not
  compared yet.
- Files that fail to parse at base or head are not analysed.
